Simple Install Note

  1. Tap Download EduPulse v1.5.0 above and wait for app-release.apk to finish downloading.
  2. Open the downloaded file from your browser or Downloads folder.
  3. If Android asks permission, tap Settings → Allow from this source (or Install anyway if Play Protect prompts), then tap Install.
  4. If upgrading from an older version and Android shows a package conflict, uninstall the old app first and install app-release.apk.
